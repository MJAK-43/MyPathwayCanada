# Design System Notes

This folder is reserved for future UI governance documents, component specs, accessibility rules, and token documentation.

Current front-end architecture lives in:

- `assets/css/variables.css`
- `assets/css/typography.css`
- `assets/css/layout.css`
- `assets/css/components.css`
- `assets/css/responsive.css`

This project intentionally separates design system thinking from page implementation so the UI can scale without CSS sprawl.
